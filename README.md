# Student JARVIS V2
No-camera/no-microphone student dashboard with futuristic UI, task manager, AI assistant interface, Pomodoro timer, CGPA tool, expenses, notes, profile and local backup.

## Publish on GitHub Pages
Upload all files to your existing `student-jarvis` repository and commit them to `main`. GitHub Pages will redeploy automatically.

## Important about AI
The AI Assistant UI in this V2 is a safe demo mode. Do NOT put an OpenAI API key in `app.js` or any browser code. To add real AI, deploy a small server-side API (for example on Vercel) and keep the secret in server environment variables.
