# Student JARVIS — V1

A responsive, no-camera/no-microphone student dashboard built with plain HTML, CSS and JavaScript.

## Features
- Dashboard and task manager
- Subjects and grades
- Weekly timetable
- Expense tracker
- Notes
- Pomodoro study timer
- Local browser storage
- JSON backup/export/import
- Mobile responsive JARVIS-style UI
- No external libraries or backend required

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub account if needed.
2. Create a new public repository, for example `student-jarvis`.
3. Upload `index.html`, `style.css`, `app.js`, and `.nojekyll`.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select `main` and `/(root)`, then Save.
7. GitHub will show your live site URL in the Pages section.

For a user site, the repository can instead be named `<your-username>.github.io`.
